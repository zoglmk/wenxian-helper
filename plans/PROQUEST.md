# ProQuest 站点支持

本版范围：学位论文与期刊全文，按浏览器当前会话权限下载。未登录可下载公开全文；已登录且有全文权限时使用网站已提供的下载入口。与知网并列，复用清单、跨页选择、队列、文件名/子目录、下载 ID 跟踪和导出；没有新增生产依赖或扩大主机权限。

## 接入约定

- `provider: "proquest"` 标识站点，`proquestId` 是稳定身份；不同搜索页、会话路径不会重复添加。原有知网记录格式保持兼容。
- `proquestAccess` 区分 `open`（明确开放标记）、`available`（当前详情提供全文标记及有效非预览 PDF 入口）、`preview` 和 `unknown`；`pdfReady` 表示已找到入口。它们与文献身份和下载状态分开。
- 学位论文、期刊结果仅标「全文文献」时先收藏为 `unknown`，显示「收藏待确认」，获取链接后才确认权限。预览和仅摘要结果不收藏，全文字样本身不授予下载资格。
- 所有详情请求使用浏览器已有会话并禁用缓存。每次下载重新检查权限、刷新媒体地址，并校验实际 PDF 文件头；登录本身不是下载凭据。退出登录、权限失效或变为预览时跳过，不复用旧签名。
- 「订购」与可用下载按钮共存时，只使用已获授权的全文入口，不触发订购；不代登录，不构造签名，不改写媒体地址。签名链接不写入清单或日志。
- 期刊保存 `docType: "J"`、刊名、卷期页、年份和 DOI，优先完整作者列表；BibTeX/RIS 按期刊文章导出。学位论文保留 `docType: "D"` 及原导出类型。
- `resolveProquestPaper()` 负责详情解析，`downloadProquestPaper()` 负责该站点下载；知网继续使用原 MAIN world iframe。
- 翻页由用户操作，每页收藏累积到同一清单，已有取消勾选状态保留。「添加本页」同时显示累计和本次新增数，只扫描当前加载的结果。

## 尚未支持

自动登录、购买、预览文件下载、任意机构代理页面适配及自动遍历全部搜索页不在本版范围。当前会话入口无法确认全文时会跳过，并提示用户在网站确认权限。

## 验证与发布边界

具体结果见 [tests/README.md](../tests/README.md)。公开期刊已实际下载验证；登录权限、撤权与恢复使用独立浏览器的虚构会话样例验证，真实机构账号待用户验收。两轮改动分次提交并同步到现有草稿 PR，验收确认后再合并、打 tag 和发布。
