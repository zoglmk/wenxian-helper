## 原始问题与验收清单

| 问题 | 当前证据 / 位置 | 下一版验收要求 |
|---|---|---|
| 下载归属与完成误判 | `waitForDownload()` 未使用 `expectedUrl` 过滤下载，完成等待超时直接返回成功 | 其他文件下载不影响论文状态；仅确认 `complete` 时显示完成；慢下载与中断状态明确 |
| 文件夹标记残留 | `background.js` 的 `pluginDownloadPending` 只标记下一个下载 | 标记关联具体任务并可清理，验证码或失败后不改变其他文件的保存目录 |
| 重复任务与清空后异步回写 | 下载、重试、导入等缺少统一运行保护；清空未取消异步工作 | 连续点击不重复启动；清空后旧结果不回写，不重新出现旧文献 |
| 解析失败无法重试 | `fetchPdfLinks()` 排除 `pdfFailed`，重试只处理已有 PDF 的下载错误 | 临时网络失败可重新解析；没有待处理项时提示准确 |
| 选择状态丢失 | `restoreChecks()` 将可下载项全部选中 | 取消勾选后排序、刷新、补全元数据，原有选择保持不变 |
| 无 PDF 的文献不能单独导出 | `createPaperCard()` 按 `pdfLink` 禁用复选框 | 文献可独立选择；导出按选择执行，下载再筛选可下载项并提示 |
| 并发保存覆盖 | 内容脚本和侧边栏分别读写整份 `cnkiPapers` 数组 | 跨标签页并发收藏、解析、删除不丢记录；不能只加页面内锁 |
| 作者和目录页字段错误 | 收藏时 `author: ""` 覆盖已提取作者；目录页 `date: pages` | 保留作者；页码与日期分开，未知日期留空；旧清单字段不被误改 |

## 后续按范围决定

- DOI 查询失败后允许更新原条目重新查询；进度按实际队列统计新增、跳过与失败。
- 保留英文作者完整姓名与必要空格。
- 文本渲染统一转义或使用 `textContent`，链接校验协议；不把未验证的注入风险直接称为任意代码执行漏洞。
- 第三方 PDF 判断结合文件特征与响应类型，不能只判断“不是 HTML”。
- 界面版本从 manifest 读取，避免多处手动维护。
- 隐私说明完整列明 DOI 查询的实际第三方来源及发送字段。
