# Privacy Policy - 文献助手

Last updated: 2026-09-23

## Overview

文献助手 is a Chrome extension that helps users batch download academic papers from CNKI (China National Knowledge Infrastructure) and dissertations, theses, and journal full text available to the user from ProQuest. We are committed to protecting your privacy.

## Data Collection

**The extension developer does not operate a server that receives your saved paper list or settings. The extension sends requests to the services listed below when you use their features.**

All data generated by this extension is stored locally on your device using Chrome's built-in `chrome.storage.local` API, including:

- Your saved paper list (titles, authors, download links)
- Extension settings (folder preferences, toggle states)
- Library / proxy hostnames you explicitly add (URL paths, query parameters and login information are not saved by this setting)

Your saved list and settings are kept locally. The paper URL or DOI needed for a lookup or download is sent to the corresponding service; a full saved list is not uploaded to the extension developer.

## Network Requests

The extension makes network requests solely to provide its core functionality:

- **cnki.net** — to fetch paper detail pages and trigger PDF downloads, using your existing CNKI login session
- **www.proquest.com / proquest.com** — to read dissertation and journal metadata and check current full-text access. Detail lookups use the existing browser session and bypass the cache; the extension does not read passwords, log users in, or initiate purchases. The saved list retains the document ID and canonical detail URL, without search-session paths or query parameters.
- **media.proquest.com** — to check a short PDF header and download accessible full text using the exact link supplied by ProQuest. Signed media links are refreshed for each download and are not persisted in the extension's paper list or logs. Chrome may retain download URLs in its own download history.
- **Library / institutional proxy domains** — to access CNKI through your institution; custom domains require your explicit browser permission
- **api.unpaywall.org** — to look up open-access PDF links for English literature by DOI (Unpaywall is a free, legal open-access database)
- **sci.bban.top** — when Unpaywall does not return a PDF link, the DOI is included in a request to this third-party PDF endpoint; a short file header is checked before showing the link
- Various academic repository domains — to retrieve publicly available PDF files

Requests are made on your behalf. CNKI and ProQuest requests use existing browser sessions. ProQuest access is checked again before downloading; preview-only or unconfirmed access is skipped. Browser downloads and PDF checks may use cookies applicable to the media host. No data from these requests is sent to the extension developer.

## Permissions Explanation

| Permission | Why it's needed |
|------------|----------------|
| `storage` | Save your paper list and settings locally |
| `downloads` | Trigger PDF downloads and set the save folder |
| `scripting` | Inject a script into CNKI pages to trigger downloads (CNKI's download mechanism requires page-context execution) |
| `sidePanel` | Display the paper management UI in the browser sidebar |
| `webNavigation` | Detect page redirects to identify download errors (e.g., CAPTCHA pages) |
| `host_permissions` | Access CNKI, institutional proxy pages, DOI services, and ProQuest pages / PDF hosts. ProQuest access is limited to `www.proquest.com`, `proquest.com`, and `media.proquest.com`. |
| `optional_host_permissions` | Let you add a library / proxy domain at runtime. Access covers the domain you approve and its subdomains, over HTTP / HTTPS on any port. Declaring optional patterns does not grant access to all sites. You can remove each custom domain and its permission in the sidebar. |

## Third-Party Services

- **Unpaywall** (api.unpaywall.org): Receives the DOI you submit and the fixed contact email bundled with the extension (not your personal email). Used for metadata and open-access links. See [Unpaywall's privacy policy](https://unpaywall.org/legal/privacy).
- **sci.bban.top**: Receives the DOI during the fallback lookup and the PDF request if you download from this source. This is an independent third-party service; the extension developer does not operate it.
- CNKI, library proxies and PDF hosts receive the requested URL and the browser cookies applicable to that host. The extension does not send your CNKI password to DOI lookup services.
